# 企业报销流程指引

本文档详细说明企业费用报销的完整流程、所需材料和注意事项。

## 报销基本流程

报销流程分为五个阶段：提交申请 → 部门审核 → 财务复核 → 领导审批 → 打款。

1. **提交申请**：员工通过系统提交报销申请，填写费用类型、金额、事由，并上传发票
2. **部门审核**：部门主管在 2 个工作日内审核报销的合理性和必要性
3. **财务复核**：财务人员审核发票真实性和合规性，核对费用标准
4. **领导审批**：根据金额级别由相应领导审批（见审批级别规则）
5. **打款**：审批通过后，财务在 3 个工作日内完成打款

## 审批级别规则

报销金额决定审批层级。

- 金额 2000 元以下：部门主管一级审批
- 金额 2000-5000 元：部门主管 → 财务主管两级审批
- 金额 5000-10000 元：部门主管 → 财务主管 → 总监三级审批
- 金额 10000 元以上或含超标项：部门主管 → 财务主管 → 总监 → 总经理四级审批

## 所需材料

报销时必须提供以下材料，缺一不可。

- **发票原件或电子发票**：必须是国家税务系统可查验的真实发票
- **报销事由说明**：详细描述费用产生的业务背景和必要性
- **出差申请单**（差旅费必须）：出发前已审批通过的出差申请
- **招待申请单**（招待费必须）：事前已审批通过的招待申请
- **采购清单**（办公用品必须）：列明采购物品、数量、单价和用途
- **培训通知**（培训费必须）：正式的培训通知或邀请函

## 发票要求

发票必须符合以下规范，否则将被退回。

- 发票必须是税务局监制的正规发票，电子发票需有有效的发票代码和号码
- 发票抬头必须为公司全称
- 发票内容需与报销类型一致（如差旅费对应交通票和住宿票）
- 发票日期需在报销日期之前且不超过 3 个月
- 单张发票金额超过 1000 元需在税务系统查验真伪
- 增值税专用发票需同时提供抵扣联

## 报销时限

- 费用发生后 30 个自然日内提交报销申请
- 超过 30 天未提交的需书面说明原因
- 超过 90 天的费用原则上不予报销
- 年底（12 月 31 日）之前需完成当年所有费用的报销

## 常见退回原因

以下情况报销将被退回并要求重新提交。

- 发票信息不完整或不清晰
- 费用超出标准且未提交超标说明
- 缺少必要的审批材料（出差单、招待单等）
- 报销类型与发票内容不符
- 部门预算余额不足且无特殊审批
- 发票已过有效期（超过 3 个月）
