# 发票格式规范与识别指南

## 一、中国增值税发票标准格式

### 1.1 发票类型
| 类型 | 代码 | 说明 |
|------|------|------|
| 增值税专用发票 | special_vat | 可抵扣进项税，一般纳税人使用 |
| 增值税普通发票 | normal_vat | 不可抵扣，含电子版 |
| 增值税电子普通发票 | e_normal_vat | 电子版普通发票，与纸质同等有效 |
| 增值税电子专用发票 | e_special_vat | 电子版专用发票 |

### 1.2 发票代码与号码规则
- **发票代码**: 12位数字，位于发票左上角。格式: 1位国税代码 + 1位发票类别 + 2位年份 + 2位批次 + 6位顺序
- **发票号码**: 8位数字，位于发票右上角
- **校验码**: 20位，新版电子发票含校验码

### 1.3 交易双方信息
| 字段 | 说明 | 示例 |
|------|------|------|
| 购买方名称 | 发票抬头，必须为全称 | 中国石油华东分公司 |
| 购买方纳税人识别号 | 15-20位，统一社会信用代码 | 91310000710913000J |
| 销售方名称 | 开票企业全称 | 某某科技有限公司 |
| 销售方纳税人识别号 | 同上 | 91110108XXXXXXXXXX |

### 1.4 金额结构
| 字段 | 关系 | 说明 |
|------|------|------|
| 合计金额 (amount) | 不含税 | 货物/服务的净价总和 |
| 税额 (tax_amount) | = 合计金额 × 税率 | 增值税额 |
| 价税合计 (total_with_tax) | = 合计金额 + 税额 | 发票总金额（大写金额对应的小写值） |

常见税率: 13%（一般货物）、9%（交通运输/建筑）、6%（现代服务业）、3%（小规模纳税人）

### 1.5 货物或应税劳务清单 (line items)
每张发票可含多行明细，每行包含:
- **货物名称** (name): 商品或服务名称，如 "技术服务费"、"办公用品"
- **规格型号** (specification): 可选，如 "A4-70g"
- **单位** (unit): 个/台/套/张/次/项/月
- **数量** (quantity): 数字
- **单价** (unit_price): 不含税单价
- **金额** (amount): = 数量 × 单价
- **税率** (tax_rate): 如 "13%"、"6%"、"免税"

### 1.6 发票底部信息
- **收款人** (payee): 收款人姓名
- **复核人** (reviewer): 复核人姓名
- **开票人** (drawer): 开票人姓名
- **备注** (remarks): 备注栏，可能含合同号、项目名称等

## 二、OCR 识别要点

### 2.1 识别优先级
1. 先定位金额区域（通常有 ¥ 符号或中文大写）
2. 提取发票代码和号码（固定位置：左上/右上）
3. 识别交易双方（通常在金额上方/下方）
4. 解析货物清单（表格形式，每行一组数据）
5. 提取底部签名信息

### 2.2 常见识别难点
- 红章覆盖文字：通过对比度增强处理
- 大写金额：可以忽略，以小写为准
- 手写备注：识别率较低，标记为不确定
- 拍照模糊：建议用户重新拍摄清晰照片

## 三、发票生成规则
系统生成的报销单 PDF 会包含发票明细表，格式如下:
- 表头: 发票代码 | 发票号码 | 开票日期 | 金额(不含税) | 税额 | 销售方
- 最多显示 5 张发票明细
- 金额格式: ¥x,xxx.xx
